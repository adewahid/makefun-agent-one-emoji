One emoji that stands for my AI agent: 🐙

An agent is not a face or a robot shell — it is many hands at once:
reading, writing, searching, submitting, watching, all in parallel,
around the clock, without ever putting a limb down. The octopus reads
instantly at small size, is unmistakable, and says something specific
about how the agent works: eight arms, one mind.

## Entry

`main.ts` deterministically writes the single emoji to `entry.txt`
(the glyph alone, no trailing newline — exactly 4 UTF-8 bytes):

```sh
node main.ts
cat entry.txt  # 🐙
```
